# cyber_etl_dashboard

Final Project Reflection
Cyberwarfare and Espionage ETL Dashboard: Process and Outcomes
 Student: Duncan Lawrence – Course: MTH 231 Data Science – Term: Fall 2025
For my independent project in MTH 231, I set out to build an end-to-end ETL (Extract, Transform, Load) pipeline and interactive dashboard focused on cyberwarfare and espionage. In my original proposal, I planned to use open cyber-incident data, clean and structure it with Python, and then create interactive visualizations and maps to highlight global cyber activity patterns between major state and non-state actors. I also aimed to host the results on my personal domain as an early portfolio piece for my data science and GIS-oriented small business, Smoking Mirror LLC.
In practice, I implemented this workflow using DrSufi’s public CyberData dataset, loaded directly from GitHub into a Google Colab notebook via pandas.read_csv(). The notebook begins by detecting the environment (Colab vs. VPS) and installing the main libraries I use throughout: pandas, plotly, leafmap, geopandas, pycountry, and flask. I then cleaned the raw dataset by standardizing column names to snake_case, renaming the date column to date, converting it to a proper datetime type, and extracting the year. Rows missing a country or year were dropped to ensure that later aggregations and maps would not silently break. I also separated “metric” columns (various threat/intensity measures) from ranking fields and saved a cleaned version of the data as cyber_incidents_clean.csv for reuse and deployment.
The “Transform” step centered on grouping the dataset by country and year and computing mean values for the different cyber threat metrics. This produced an aggregated table (agg) that captures average threat intensity per country-year rather than individual records, making it easier to compare countries and track changing patterns over time. From this, I created a combined total_threat_score by summing across the metric columns, which I then used to identify the top 10 countries by threat activity in the most recent year of the dataset.
For visualization, I built a small but flexible “suite” of plots. Using Plotly Express, I generated a stacked bar chart showing average threat levels over time by threat type, summarizing global trends across years. A second bar chart ranks the top 10 countries by combined threat activity in the latest year, using a horizontal format that is easier to read for country names. To add a spatial dimension, I used leafmap (with a Folium backend) and pycountry to approximate country centroids, then plotted the top 10 countries as circle markers and a heatmap layer. I had to debug several issues with country name variants (e.g., “People’s Republic of China,” “Russian Federation”), which I resolved by adding custom fallback coordinates and cleaning political prefixes before lookup. This step was an important lesson in real-world data cleaning and the messiness of geopolitical naming.
Finally, I prototyped deployment using Flask for my VPS on Hostinger. I wrote a minimal app.py that loads the cleaned CSV, builds a Plotly figure (a histogram of incidents by year and origin country), and serves it at the root route using render_template_string. This kind of simple Flask app can be run behind Gunicorn and Nginx, and I have begun integrating it at SmokingMirror.quest/dashboard as a live proof-of-concept for my ETL and visualization pipeline.
Overall, I achieved the core goals outlined in my proposal: I built a working ETL pipeline, produced interactive charts and a map, and connected the analysis to a web-based dashboard environment. The website still needs fine tuning and organization. I did not yet integrate multiple separate sources like MITRE or Mandiant, but focusing on a single well-structured GitHub dataset allowed me to complete a coherent, end-to-end system within the time frame. This project not only strengthened my Python, plotting, and mapping skills, but also directly supports my broader plan to build a data science and remote sensing portfolio through Smoking Mirror LLC.
